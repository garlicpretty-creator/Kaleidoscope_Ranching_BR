## 森羅物語：樂牧 1.1（Kaleidoscope Ranching）

> **非官方附加包。** 《森羅物語：樂牧》是玩家自製的原創系列擴充，不是 Java 模組的移植，與《森羅物語：廚房》（Kaleidoscope Cookery）的作者沒有隸屬或合作關係，也不是 Mojang 或 Microsoft 的官方產品，未經其認可。Minecraft 是 Mojang Synergies AB 的商標。

《森羅物語：樂牧》是一款以「養動物」為主題的 Minecraft 基岩版附加包，把原版「餵兩下就繁殖」的牲畜，變成需要照顧、也會回報你的牧場。它以《森羅物語：廚房》v1.6.6 為宿主，透過廚房公開的擴充 API 註冊食譜與手冊內容，不修改廚房本體。1.1 在 1.0 的「養、收、宰、加工、入菜」之後，補上更深的加工鏈、役用動物、動物作息與健康。

### 1.1 的內容

- **肉類與內臟**：屠宰時多了取內臟的刀；絞肉機做絞肉與生香腸；空的屠宰掛架可以風乾臘腸、臘肉、臘鴨腿、牛肉乾；14 道新料理。
- **蛋奶與起司**：擠奶架、奶油分離器、冰淇淋桶三個新方塊；四種奶各壓出自己的乳酪；熟成 7 天得陳年乳酪輪，下方有營火得煙燻乳酪輪；滿心的豬會拱出松露；15 道新料理。
- **皮革、絨毛、布料**：油鞣皮革、皮圍裙、套索；紡車與織布機把毛做成毛線、絨線、毛呢布、絨布；可染成 16 色的毛毯、羽絨枕、羽絨被、毛帽、圍巾。
- **孵化與飼料**：蛋殼磨鈣粉做鈣質飼料，母禽有機會多下一顆蛋；照蛋燈；青貯桶。
- **役用與管理**：水牛裝上挽具與犁可以耕地；牧笛把馴服的狼變成牧羊犬，幫你把動物趕回集合點；畜欄門只為玩家打開；氂牛可以背 15 格的馱袋。
- **動物作息**：十種動物晚上會睡覺，各有睡姿並閉眼。睡的地方有遮蔽、附近有乾草架或毛毯，好感度會上升；在雪地露宿會下降。管理員可以關閉。
- **健康**：缺水或畜欄髒亂的動物可能生病，生病只會停產，不會死；用獸藥治療，用肥皂預防。管理員可以關閉。
- **可放置食物**：三種乳酪輪放在地上用刀切；披薩、起司火鍋、六道燉菜與兩道焗烤可以放下來分四份吃。
- **觀察手冊**：對動物使用，一頁看完牠的好感度、今日需求、健康、作息、產出、繁殖與裝備。
- **系列整合**：裝了《森羅物語：酒館》可以做乳品調飲與奶酒（用角杯裝）；裝了《森羅物語：漁歌》可以拿雞胗、豬肝、三種絞肉、乳酪塊當魚餌，魚骨磨鈣粉，海鹽加快風乾。
- **給附加包作者**：對外 API 新增 1.1 的能力與標籤契約，其他附加包可以註冊自己的動物、飼料、獸藥與配方材料。

### 需求

- Minecraft 基岩版，最低引擎版本 1.26.1。
- **必要**：《森羅物語：廚房》v1.6.6。沒有廚房就無法啟用樂牧。
- 可選：《森羅物語：酒館》（非官方）、《森羅物語：漁歌》。沒裝時對應的整合內容不會出現，其餘照常。
- 不整合《森羅物語：煙火》（Grilling）。

### 安裝

1. 先安裝《森羅物語：廚房》v1.6.6。
2. 下載樂牧的 `.mcaddon` 檔，開啟檔案即可匯入 Minecraft。檔案裡包含行為包與資源包。
3. 在世界設定裡，同時啟用廚房和樂牧的行為包、資源包。
4. 要用酒館或漁歌的整合，把它們也一起啟用。
5. **先備份世界**，或用新世界測試。樂牧會把原版的牛、羊、山羊、豬、雞、兔換成自己的版本。

### 請先知道

- 1.1 的內容目前只在模擬的腳本 API 上測過，還沒有在遊戲內實測。可能遇到外觀、碰撞或與其他附加包配合上的問題。
- 部分外觀還沒做：毛帽、圍巾、皮圍裙穿上後沒有外觀；挽具、犁、動物披毯、馱袋在動物身上看不到；掛架上風乾中的肉沒有外觀。
- 需要漁歌配合的魚漿、樂牧食材進漁歌的鍋具，延後到之後的版本。
- 完整清單見 [1.1 更新說明](RELEASE_NOTES_1.1.md) 的「已知限制」。
