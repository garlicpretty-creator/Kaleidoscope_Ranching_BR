2026-11-16 整理。1.1 的程式已全部寫完並合進 main（M7～M11，加上後補的奶酒、角杯、馱袋，#40 的方塊模型與可放置食物，#43 的其餘圖示，#44 的燉菜與焗烤可放置食物）。本文列出發佈 1.1 之前還沒做的事，依類別分成六項，最後排出建議的順序。

## 一、遊戲內實測

最優先。模擬環境測不到的部分：方塊與實體的外觀、碰撞、客戶端動畫、介面，以及其他附加包的實際反應。請在新世界或 luosen 的複本上測，不要用正式存檔。

### 1. 1.1 各線的流程

| 項目 | 要確認的事 |
| --- | --- |
| 肉類線與內臟線（M7） | 絞肉機的配方；掛架在風乾與屠宰之間切換不出錯；水槽洗內臟；臘味煲仔飯、滷大腸從屠體做到完成 |
| 蛋奶線與起司線（M8） | 擠奶架接漏斗後三天不用手動操作；奶油分離器的自動化；四種奶各壓出對應的乳酪；放滿 7 天得到陳年乳酪輪 |
| 皮革、絨毛、布料線（M9） | 套索的視線判定；紡車與織布機接容器的自動化；16 色毛毯；鈣質飼料讓母禽多下蛋 |
| 役用、管理與作息（M10） | 睡姿會不會穿模或浮空；吵醒的各種條件；趕畜的推力；畜欄門擋不擋得住所有樂牧動物；犁的耕地範圍 |
| 健康（M11） | 生病只停產不致死；獸藥、肥皂有效；觀察手冊關掉疾病後完全不觸發 |
| 可放置食物（#40、#44） | 三種乳酪輪放地上用刀切；披薩、起司火鍋分四份吃，火鍋最後還碗；六道燉菜與兩道焗烤從鍋或盤分食 |
| 物品給予 | `give` 重複掉落的修正（#40）在遊戲內確實不再多掉 |

### 2. 後補的三樣

| 項目 | 要確認的事 |
| --- | --- |
| 奶酒 | 酒館收下這份擴充（含兩種奶的液體）；開蓋的酒桶看得到奶的液面；奶酒能用角杯裝出，喝完角杯回來 |
| 馱袋 | 蹲下放物品、空手開清單都順手；氂牛死亡時袋裡的物品一起掉出（這部分交給遊戲本身處理，要實機確認） |
| 毛帽、圍巾 | 自訂穿戴物在細雪中有沒有皮革的防凍效果。沒有的話，改用腳本在細雪中替戴著的玩家清除凍結 |

### 3. 系列握手

| 對象 | 要確認的事 |
| --- | --- |
| 酒館 | luosen 上的酒館版本有沒有 `custom_fluids`、`external_fluid_visuals`、`shaker_recipes`、`external_shaker_inputs`；缺了液體相關的能力，整份擴充可能被拒收（酒館不接受有錯的整包），要改成依能力清單分批送 |
| 漁歌 | 魚餌是否生效；魚骨磨鈣粉、海鹽加快風乾 |
| 廚房 | 1.1 新增的料理在廚房站點都做得出來，手冊章節正常 |

### 4. 伺服器

在 luosen 連續運行一週，腳本看門狗沒有警告。這是 M6 與 M11 共同的驗收標準，兩次都還沒做。重點看大量動物同時入睡與醒來的那一刻（目標是 50 隻同時入睡、被吵醒都不卡頓）。

## 二、美術

程式先行，美術目前大多是程式畫的暫代版。

| 項目 | 現況 | 要做的事 |
| --- | --- | --- |
| 物品圖示 | 已全部換成 RetroDiffusion 圖示（#37、#43）；受精蛋沿用一般蛋的圖示加標記 | 實測時看有沒有不清楚、要重挑的 |
| 睡姿與眼皮 | 已完成：十種動物依企劃書逐種擺好睡姿，加上閉眼與呼吸起伏（預覽 `docs/art/sleep_poses_preview.png`） | 實測時看有沒有穿模、浮空，以及前後方向對不對 |
| 穿戴與掛載外觀 | 已完成：毛帽、圍巾、皮圍裙有附件模型；挽具、犁、動物披毯、馱袋以另一層模型顯示在動物身上，由同步的實體屬性切換（預覽 `docs/art/gear_preview.png`） | 實測時看：穿戴物在玩家身上的位置；皮圍裙的裙片固定在身體上，走路或奔跑時腿可能穿出裙片（目前接受）；拿在手上時顯示的是自製的圖示薄片（綁在手的骨頭上），位置與大小要在遊戲裡調；動物裝備是否跟著走路與睡姿、會不會穿模；剪過毛的羊換成貼身的披毯；裝鞍的豬披毯整塊蓋過鞍（鞍看不到） |
| 掛架風乾 | 已完成：掛架依風乾中的件數（1～4）顯示掛在橫樑上的肉條；更新前就掛著肉的掛架，載入世界後由腳本補上顯示（所在區塊載入時） | 實測時看外觀與方向 |
| 毛毯 | 程式版模型，16 色是同一張貼圖染色 | 決定要不要每色各畫一張 |
| 奶的液面 | 程式產生的奶色貼圖 | 實測後再決定要不要重畫 |

美術授權照舊：全部原創，不複製廚房（CC BY-NC-SA）與酒館的資源檔。

## 三、平衡

實測後依手感調整：
- 疾病的發病機率與恢復速度
- 鈣質飼料多下一顆蛋的機率（目前 30%）
- 睡得好與寒冷對好感度的加減
- 各加工方塊的時間
- 新料理的飽食度
- 馱袋的格數（目前 15 格）

數值都集中在 `data/` 的表格與各系統開頭的常數，調整時不用改邏輯。

## 建議順序

1. **實測主要流程**：新世界跑一輪 1.1 各線，加上後補的三樣與系列握手，記下問題。
2. **修正**：照實測紀錄修程式；酒館能力不齊的話，改成分批送出。
3. **美術**：穿戴與掛載外觀、掛架風乾的外觀。
4. **平衡**：第二輪實測時一起調數值。
5. **伺服器一週**：在 luosen 連續運行一週。
6. **發佈**：改版本號、寫更新說明、打正式包。
