# 1.1 收尾：美術精修（設計）

2026-11-16。依 `docs/1.1_收尾企劃書.md` 第二節與使用者追加的兩項需求（可放置食物精緻化、動物外觀更好看）。

## 目的

發佈 1.1 之前，把程式畫的暫代美術補到能上架的品質。使用者要的是「外觀更好看」。

## 範圍（依序，各開一個分支，不直接推 main）

1. **可放置食物精修**（13 個模型，`art_src/m4_scripts/placed_food.py`、`cheese_wheel.py`）
   - 三種乳酪輪由方塊改成圓輪，切開露出切面。
   - 六道燉菜不再只換顏色：各有立體配料浮出湯面（獅子頭四顆丸子、煲仔飯砂鍋配臘味等）。
   - 披薩配料有厚度；兩道焗烤加隆起的焦皮。
   - `piece_1`～`piece_4` 的骨骼約定不變，行為包程式不動。
2. **企劃書第二節的缺口**
   - 毛帽、圍巾、皮圍裙的穿戴外觀（附件模型）。
   - 挽具、犁、披毯、馱袋在動物身上依動態屬性顯示。
   - 掛架風乾中的肉。
   - 毛毯維持單張貼圖染 16 色（Claude 的判斷，使用者已同意）。
3. **M1 六種動物造型**（牛、羊、山羊、豬、雞、兔；`art_src/m4_scripts/m1_animals.py`）
   - 照原版比例修：羊與山羊的口鼻、羊毛體積、牛角、雞腳與雞冠、兔子比例；貼圖補明暗。
   - 骨骼名稱不變；重擺這六種的睡姿與閉眼；重跑屠宰掛架。
4. **發佈文件**：1.1 更新說明與發佈頁文字，標明「非官方」。

## 不做

- 遊戲內實測、平衡、伺服器一週、GitHub 分支整理、等漁歌的項目。
- 版本號改 1.1.0 與正式打包：留到實測通過後。
- 不複製廚房、酒館或原版的資源檔；與原版對齊只指風格與比例。

## 做法的選擇

- 動物：比較過「只重畫貼圖」與「重做造型」。最顯眼的問題（豬臉、比例）在造型上，貼圖補不了，所以選重做造型，代價是睡姿要重擺。
- 生成的檔案一律改 `art_src/` 的腳本，不手改輸出。

## 驗收

每塊做完：`npm run generate` 重跑無多餘差異、`npm run validate` 與 `npm test` 通過、對應的預覽圖更新並交給使用者看。遊戲內外觀仍需使用者實測。
