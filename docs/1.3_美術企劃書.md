# 樂牧 1.3 美術企劃書

2026-11-19。1.3 只更新美術，不加新功能、不改數值、不改物品或方塊 ID。

做法：把全部 242 個物品圖示、13 種動物、所有方塊模型並排比對，挑出「跟別的太像，在背包或地上分不出來」或「不像現實中的東西」的項目重畫。規則照舊：全部原創，不複製廚房（CC BY-NC-SA）或原版的貼圖與模型；骨頭名稱不改；眼睛顏色固定；低面數、細節畫在貼圖上。

## 二、動物模型與貼圖

| 動物 | 問題 | 重畫方向 |
| --- | --- | --- |
| 水牛幼體 | 像小黃牛 | 灰黑色、寬鼻、小角芽 |
| 氂牛幼體 | 像小黃牛、粉紅鼻 | 深褐長毛、深色鼻 |
| 鵝幼體 | 跟小鴨一樣 | 灰黃色、脖子較長、嘴偏灰 |
| 山羊 | 跟剪毛的羊幾乎一樣 | 臉長、山羊鬍、細腿、尾巴上翹 |
| 牛 | 鼻子跟豬一樣粉紅方塊 | 寬口鼻、深色或肉色鼻頭，花斑自然 |
| 公母 | 綿羊、水牛、兔子、鵝的公母幾乎一樣 | 公的加大角、肉瘤或體型差異 |
| 羊駝 | 吃草時脖子整段往下掉 | 加脖子骨頭，低頭時脖子彎下去（動作照新骨頭重新產生） |
| 全部 | 沒有 Blockbench 專案檔 | `bbmodel.py` 也輸出動物 |

## 三、方塊模型

| 問題 | 項目 | 重畫方向 |
| --- | --- | --- |
| 六個都是鐵箍木桶 | silage_barrel、feed_mixer、pickling_vat、food_waste_bin、butter_churn、ice_cream_churn | 青貯桶改成封膜高桶；飼料攪拌機改成手搖攪拌槽；醃漬缸改成陶缸；廚餘桶改成有蓋的桶；攪乳桶保持細長木桶；冰淇淋桶是木桶套鐵罐加冰 |
| 五個燉菜都是同一個鐵鍋 | placed_old_duck_soup、braised_brisket、yak_stew、goose_stew、lion_head_meatballs | 依菜色換砂鍋、陶鍋、鑄鐵鍋，鍋裡的主料看得見 |
| 不像現實 | cream_separator、meat_grinder（像機器人臉） | 照真實的手搖奶油分離器、手搖絞肉機 |
| 不像現實 | down_pillow、down_quilt（藍色平板） | 鼓起的枕頭、蓬鬆的被子 |
| 不像現實 | horn_decor | 牛角掛在木板上的壁飾 |

翻頁格（crank_0..3 等）、busy 與 piece_N 的命名，選取框高度與 `tools/gen_blocks.mjs` 一致；改高度要一起改。
