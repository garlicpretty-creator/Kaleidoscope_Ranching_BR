# M10 役用、管理與作息（1.1）

企劃書 1.1 的第四個開發階段。程式完成；十種動物的睡姿與閉眼已依企劃書逐種擺好（2026-11-16），新物品與方塊的美術見各說明。

## 動物作息（睡覺）

- **什麼時候睡**：遊戲時間 13000 到 23000，玩家附近 64 格內、沒被牽著的樂牧動物會趴下（被拴在拴畜樁、擠奶架上的也算被牽著，所以不睡）。每 30 秒檢查一次，所以入夜後最多半分鐘內陸續睡下。
- **起床**：23000 後的第一次檢查，動物在 10 秒（200 刻）內一隻隻起身；公雞也在這時啼叫。
- **睡姿**（`tools/gen_sleep.mjs`，依各物種的骨架擺，成體與幼體各自計算）：
  - 牛、水牛、氂牛、羊、山羊：趴臥，前腳往後收在胸下、後腳往前收在腹下，頭低垂並稍微偏向一側，尾巴貼地。
  - 豬：側躺，腳伸直。身體骨頭的轉軸移到軀幹中央，翻身時留在原地。
  - 雞、鴨：蹲坐，腳收起，頭轉向後方擱在背上。鵝：長脖子往後折，頭埋進背上的羽毛。
  - 兔：縮低，耳朵往後貼背，頭低下。
  - 全部：軀幹慢慢起伏呼吸；睡著時不轉頭看玩家，也不移動。
- **閉眼**：眼睛是頭部正面畫上的眼珠與眼白（`plain_eyes`），每個眼睛像素前面加一片薄薄的眼皮，貼圖取正上方的皮毛像素，放在 `lids_a`／`lids_b` 骨頭；只在睡著時顯示。眼皮沿用動物自己的貼圖，所以每種毛色都對得上。
- **不穿地**：趴臥時頭只低到口鼻、鬍子、角都還在地面以上；垂在肚子下的乳房、氂牛的長毛裙會壓扁貼著身體；綿羊腿上的毛套收到跟腿一樣粗。睡姿由模型的骨頭算出來，動物外型改了重跑 `npm run generate` 就會跟著調整。
- **眼睛的顏色是約定**：眼皮靠眼珠的黑與眼白的顏色找眼睛，所以頭部正面其他像素（鼻孔、黑毛）要避開這兩個顏色（`m1_animals.py` 的 `eyes()` 會自動避開）；`npm run validate` 會檢查每種動物都有 `lids_a`／`lids_b`。
- 預覽圖：`docs/art/sleep_poses_preview.png`（`art_src/m4_scripts/sleep_preview.py` 產生；每列為醒著、睡著的成體，再來是醒著、睡著的幼體）。
- **吵醒**：受傷、被牽繩或套索牽住、10 格內有敵對生物（公鵝守夜，16 格）、被玩家推擠、搖牧鈴、吹牧笛、沒戴皮手套就擠奶。被吵醒後安靜 5 秒（100 刻）才會再睡。走近、撫摸、用奶瓶餵幼體不會吵醒。
- **睡得好**：入睡時頭上 8 格內有方塊、4 格內有乾草架或地毯，好感度 +4 點（每心 20 點）。
- **寒冷**：入睡時頭上沒有遮蔽、腳邊 2 格內有雪、細雪或冰，好感度 -4 點；披著動物披毯的不受影響，氂牛不怕冷。基岩版的腳本沒有穩定的生物群系查詢，所以用「附近有雪或冰」判斷寒冷地區。
- **每晚只結算一次**睡得好或寒冷。
- **睡著時擠奶**：會吵醒牠；副手戴皮手套就不會吵醒（#35 起奶不分品質，所以沒有降級）。
- **開關**：`/scriptevent kaleidoscope_ranching:config sleep off`（`on` 打開），或在觀察手冊的設定頁切換。關掉時，玩家附近睡著的動物會起來。

## 役用與管理

| 道具／方塊 | 配方 | 用法 |
| --- | --- | --- |
| 挽具 | 3 油鞣皮革、1 鐵錠 | 對 3 心以上的成年水牛使用就裝上。拿剪刀點水牛卸下（連同犁） |
| 犁 | 3 木材、2 鐵錠 | 對裝了挽具的水牛使用就接上，再點一次卸下。玩家用牽繩牽著水牛走時，水牛腳下與左右各一格的草地、泥土、土徑（上方是空氣）會變成耕地 |
| 動物披毯 | 3 絨布 | 披在牛、羊、山羊、豬、水牛身上，晚上不會受寒 |
| 皮手套 | 2 油鞣皮革 | 戴在副手，替睡著的動物擠奶時不會吵醒牠 |
| 牧笛 | 牛角或羊角加 1 條線 | 對拴畜樁使用：設為你的集合點。對你馴服的狼使用：牠成為你的牧羊犬（名字照舊）。在空中吹：叫醒附近 32 格的動物，並派你 48 格內的牧羊犬去趕畜 |
| 畜欄門 | 4 木棍、1 鐵粒、1 木材 | 兩格高（上方要有空位），玩家走到 2 格內自動打開、離開就關上；動物不會讓它打開 |
| 角製掛飾 | 牛角或羊角加 1 木材 | 裝飾方塊 |

**趕畜**：每半秒一次，牧羊犬附近 24 格內、離集合點超過 4 格的樂牧動物會被往集合點推，牧羊犬跑向最遠的那隻；全部進到 4 格內，或過了 30 秒就結束，並報告趕回幾隻。每次最多處理 16 隻。被牽著的動物不會被趕。

## 新事件

`animal_event` 會多出 `fell_asleep`、`woke`（附 `reason`：dawn、hurt、lead、hostile、pushed、cowbell、horn、milked、config）、`slept_well`、`herded`。

## 與企劃書的差異

- **馱袋**：已在 1.1 後補（見 M11 說明的「1.1 後補」），以表單存取氂牛身上的儲物欄。
- **睡著時剪毛**：原版剪刀的剪毛不經過腳本，目前不會吵醒、也不降級。
- **牧羊犬**：用原版馴服的狼，不是新的動物模型。
- **擠奶架**：架上的動物不睡，所以擠奶架不受作息影響。
