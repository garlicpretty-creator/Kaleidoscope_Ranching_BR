# M11 健康、對外 API 與系列握手（1.1）

企劃書 1.1 的最後一個開發階段。程式完成；新物品的圖示是程式畫的暫代圖。

## 疾病

- **什麼時候會生病**：每個遊戲日檢查一次玩家附近 64 格內的樂牧動物。連續兩天沒喝到水，或（清潔需求開著時）畜欄昨天、今天都不乾淨，有 20% 機率生病。
- **生病時**：不產奶也不下蛋、不能繁殖、好感度不會上升（下降照常）。不會死。記事本的動物頁會用紅字寫「生病了」。
- **獸藥**：在飼料攪拌桶放苜蓿、一朵花（蒲公英、罌粟或矢車菊）、一瓶水，得 1 份。拿它點生病的動物就痊癒；點健康的動物會提示牠沒生病。
- **肥皂**：任何帶 `kaleidoscope_ranching:tallow` 標籤的油脂（牛脂、羊脂）加木炭、水桶，做 2 塊（水桶留下）。拿它點動物：當天算刷過毛，當天也不會因為髒亂生病（缺水照樣會）。
- **開關**：疾病預設開啟。`/scriptevent kaleidoscope_ranching:config disease off` 或在牧場記事本的設定頁關閉；關閉後不再有動物生病，已生病的在下一次檢查時痊癒。

## 鈣質飼料（取消品質後重新設計）

企劃書原本讓鈣質飼料「提高蛋的品質」，#35 取消了品質，所以改成：母禽當天吃了鈣質飼料，下蛋時有 30% 機率多下一顆一般的蛋。飼槽會記下每隻動物今天吃的是哪一種飼料。

## 對外 API 1.1

全部寫在 [API 文件](API.md) 的「1.1 新增」與「標籤契約」：

- 8 個新能力名稱：`recipes_1_1`、`butcher_offal`、`animal_1_1`、`feed_1_1`、`remedy`、`events_1_1`、`query_1_1`、`tag_contract`。
- `register_animal` 新欄位：`sleep`、`moult`、`harness`、`coldHardy`、`forage`。換羽、拱出物、挽具與犁、耐寒都改成同時認樂牧自己和外部註冊的動物。
- `register_feed` 新類別：`ruminant`、`calcium`。
- 新事件 `register_remedy`：外部附加包的物品可以當獸藥。
- `animal_info` 新欄位：`sleeping`、`sick`、`blanket`、`harness`。
- **標籤契約**：`offal`、`mince`、`fleece`、`fine_fleece`、`hide`、`tallow`。加工配方的材料可以寫成 `{ tag }`；樂牧自己的物品也掛上了這些標籤（`data/tags.js`），所以鞣皮架的「生皮、豬皮」與紡車的「氂牛毛」「山羊絨、兔毛」配方改成用標籤，效果不變。其他附加包的物品在世界載入後由 `core/tags.js` 找到。

## 漁歌握手

偵測到漁歌（它回 `api_ready`）時：

- 用漁歌的 `register_bait` 把雞胗、豬肝（咬餌係數 0.75）、三種絞肉（0.8）、乳酪塊（0.85）註冊成魚餌。漁歌最好的餌是 0.5，數字越小越容易上鉤。
- 絞肉機多一條配方：2 份魚骨 → 1 份鈣粉。
- 醃製缸多一條配方：4 顆鴨蛋＋1 份海鹽 → 4 顆鹹鴨蛋（代替黏土）。
- 屠宰掛架風乾時身上有海鹽，就用掉一份，那一件 2 天就好（原本 3 天）。

需要漁歌配合的兩項（魚漿、樂牧食材進漁歌的鍋具）還沒做，要等漁歌開放配方註冊。

## 酒館握手

用酒館（非官方）公開的 v1 擴充 SDK。SDK 是 BSD 3-Clause 授權，連同授權檔複製在 `packs/BP/scripts/api/tavern_sdk/`，說明見那裡的 README。

- **調酒器材料**：鮮奶油、優格、脫脂奶、煉乳、香草冰淇淋，各帶自己的顏色。
- **兩杯調飲**：鮮奶油可可飲（鮮奶油、可可豆、糖）、優格莓果飲（優格、甜漿果、煉乳或糖）。這兩個是樂牧的物品，喝完留下玻璃瓶；沒有酒館時做不出來。
- **指南頁**：酒館指南多一頁「樂牧的乳品調飲」。
- **葡萄當飼料**：酒館的四種葡萄算蔬菜類飼料。
- 酒館的能力清單缺 `shaker_recipes` 或 `external_shaker_inputs` 時，SDK 不送調酒的部分。

## 1.1 後補：奶酒、角杯、馱袋

**奶酒**（`api/tavern.js`）
- 樂牧送給酒館兩種液體：鮮奶（`fresh_milk`，桶裝鮮奶）與氂牛奶（`yak_milk`，桶裝氂牛奶），倒空後留下空桶。
- 桶裝鮮奶：原版牛奶桶直接換，或空桶加三瓶牛奶、山羊奶或水牛奶。桶裝氂牛奶：空桶加三瓶氂牛奶。
- 酒桶配方：鮮奶＋優格（酒引）＋糖或蜂蜜瓶 → 奶酒；氂牛奶＋優格＋小麥 → 氂牛奶酒。
- 成品只有一種，不分酒館的 6 級熟成品質（樂牧的產品不分品質）。
- 開蓋的酒桶裡顯示奶的液面：樂牧自己的視覺實體 `milk_barrel_visual`（自己的模型、動畫、材質，沒有借用酒館的美術），液面高度用酒館設定的 `kt_art:amount`。
- 酒館指南多一頁「奶酒與角杯」。

**角杯**
- 一個牛角做成，是兩種奶酒的容器（酒館配方的 `carrier`）：用角杯從酒桶裝酒，喝完留下角杯。
- 已確認酒館接受外部物品當容器：它只檢查容器物品存在。

**馱袋**（`systems/packBag.js`）
- 油鞣皮革 5 張加毛氈 2 張做成。對成年氂牛使用就裝上；幼崽不行。
- 蹲下拿著物品對氂牛互動：整組放進馱袋（共 15 格）。
- 空手互動（不蹲下，蹲下是撫摸）：打開馱袋清單，選一組取出，最後一個按鈕取下馱袋（要先清空）。
- 儲物用氂牛自己的儲物欄（裝上時加入），物品保有名稱、附魔與耐久；氂牛死亡時馱袋本身掉落，內容物隨氂牛的儲物欄掉出。
- 基岩版無法用腳本打開實體的儲物介面，所以用表單操作。
- API：`register_animal` 新欄位 `packBag`；`animal_info` 多了 `packBag`。

**待實機確認**：酒館是否顯示奶的液面、氂牛死亡時內容物是否掉出、表單操作是否順手。
