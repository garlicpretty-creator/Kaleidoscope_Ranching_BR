# M7 肉類線與內臟線（1.1）

企劃書 1.1 的第一個開發階段：肉類線與內臟線。程式完成，美術先用程式畫的暫代圖示與絞肉機模型，之後再換。

## 內臟

屠宰掛架的分切多了一刀，接在剝皮那幾刀之後（`data/butcher.js` 的 `OFFAL_CUTS`，分切表標 `offal: true`）：

| 動物 | 內臟 |
| --- | --- |
| 豬 | 豬肝 1、豬腸 1–2 |
| 雞 | 雞胗 1 |
| 鴨 | 鴨血 1 |
| 鵝 | 鵝肝 1 |
| 牛、水牛、氂牛 | 牛肚 1 |
| 羊、山羊、兔 | 無 |

- **清洗**：手持豬腸或牛肚點水槽，用掉一格水，換成洗淨的大腸、洗淨的牛肚。水槽沒水時只有一聲拒絕的低音。
- **腸衣**：1 份洗淨的大腸在工作台合成 2 份腸衣。
- **鵝肝醬**：攪乳桶放鵝肝與奶油，半分鐘後取出，可直接吃，也能做鵝肝醬吐司。
- **當飼料**：八種生內臟（含洗淨的）都算蔬菜類飼料，可放進飼槽餵豬。

## 絞肉機

新方塊，配方為 4 個鐵錠、2 根木棍、3 塊木材。手持肉點一下就出一份絞肉，不用等：

| 放入 | 得到 |
| --- | --- |
| 生豬肉 | 豬絞肉 |
| 生牛肉、生水牛肉、生氂牛肉 | 牛絞肉 |
| 生羊肉 | 羊絞肉 |
| 任兩份絞肉＋1 份腸衣 | 2 條生香腸 |

## 掛架風乾

空的屠宰掛架可以掛最多 4 件，每件各自計時，3 個遊戲日後點掛架就取下全部做好的：

| 掛上 | 取下 |
| --- | --- |
| 生香腸 | 臘腸 |
| 五花肉 | 臘肉 |
| 鴨腿 | 臘鴨腿 |
| 牛腱 | 牛肉乾 |

- 風乾中不能掛屠體（拒絕的低音），要先取下；全部取下後掛架恢復成一般的屠宰掛架。
- 掛滿時手上還拿著要風乾的肉，若有做好的會先取下騰出位置。
- 打掉掛架：做好的掉出成品，沒做好的掉回原料。
- 牛肉乾可直接吃（隨時可吃），也是之後牧羊犬的零食。
